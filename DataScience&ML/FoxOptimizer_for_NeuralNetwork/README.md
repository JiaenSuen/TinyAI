## Neural Network
This Neural Network will have a simple two-layer architecture. Input layer 𝑎[0] will have 784 units corresponding to the 784 pixels in each 28x28 input image. A hidden layer 𝑎[1] will have 10 units with ReLU activation, and finally our output layer 𝑎[2] will have 10 units corresponding to the each of ten classes (0–9) with softmax activation.
