## **World Cities Location Clustering By KMEAN**
Try use geopy kit to get latitude and longitude of location or cities. And then with use KMEAN unsupervised machine learning algorithm to clustering similar feature of location. So It can be a dumb recommendation system recommend other silimar cities of a city which input.
